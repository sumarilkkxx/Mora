05FAQ

常见问题

Mora 会要求把所有素材上传到云端吗？

不会。本地素材合成与已有视频剪辑可以留在本机处理；只有在你选择生成新镜头时，才会按项目配置连接外部模型。

已有素材可以不调用 AI 直接成片吗？

可以。图片、视频、音频和文案足够时，Mora 可以直接组织镜头、配音、字幕、BGM 与画幅，并通过本地 FFmpeg 输出视频。

现在已经支持 AI 智能剪辑了吗？

支持。导入已有视频后，视觉模型会理解画面与声音，文本模型会结合推广对象和目标生成三版文案与三套剪辑方案，并标出 AI 推荐。你可以逐步确认、修改或选填要求重写，再由本地链路完成配音、字幕和渲染。

生成能力绑定某一家模型平台吗？

不绑定。Mora 采用 BYOK 思路，外部模型平台由你配置，调用费用由对应平台按实际使用收取。

云端生成失败后会丢失项目吗？

项目本身不会因此消失。Mora 会保存外部任务 ID、当前状态和失败原因，方便继续查询、重试或改走本地路径。

理发店视频展示的是什么能力？

它展示 AI 智能剪辑的完整路径：模型理解原片，结合门店服务和目标顾客生成推广文案与候选镜头方案，用户逐步确认后，本地完成配音、字幕、剪辑和独立版本输出。

项目如何运行？

Mora 面向本地或私有环境，可通过 Web、Electron、Docker、CLI 与 HTTP API 使用。具体安装步骤将在下一阶段的中英文 README 中完整整理。
