# Mora v0.2.0.0

此版本为 Pre-release（alpha），重点改进编辑恢复、生成调用保护和桌面交付。

## 更新

- 统一界面图标与智能剪辑工作区呈现。
- 改进编辑审查、失败恢复和批量任务执行，保留可继续处理的状态。
- 加强视频生成费用确认及模型请求参数校验，减少意外触发付费调用。
- 加固远程素材下载检查，并修复大视频上传的代理限制。
- 精简桌面安装包：排除开发缓存与说明资源，按系统和架构裁剪 ONNX 运行库，FFmpeg/ffprobe 共用一份。
- 语音识别引擎继续随包附带；模型权重沿用已有缓存和下载机制。
- 固定兼容 Intel Mac 的 ONNX Runtime 版本，并显式携带平台媒体工具，避免 Windows 缺少 ffprobe。
- 发布前在 Windows x64、macOS Apple Silicon 和 Intel 上执行测试、打包及应用启动检查。

## 下载与升级

请根据系统和芯片选择对应安装包，SHA256SUMS.txt 提供文件校验值。
升级前建议备份 Mora 用户数据目录；新版本包含数据库迁移，首次启动时自动应用。

## 已知限制

- 本版本尚未代码签名，macOS 安装包未公证。
- 云端文本、视觉、生成和语音服务仍取决于用户配置、网络、额度及服务商规则。
- 自动生成内容仍需人工检查后再发布。
