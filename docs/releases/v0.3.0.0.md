# Mora v0.3.0.0

这是 Mora 首个按正式 GitHub Release 发布的版本。本次更新集中补齐从素材、剪辑、任务恢复到桌面交付的完整工作流，同时保持项目适合个人和小团队本地使用的轻量定位。

## 主要更新

- 统一项目继续制作入口和导航，项目刷新或重启后可以恢复到对应工作流。
- 将本地项目、设置和任务状态收敛到 SQLite，并通过 Electron 安全存储隔离桌面端凭据。
- 统一后台任务生命周期和任务中心状态，支持失败恢复、过期租约回收与幂等重试。
- 新增真实制作概览，直接展示当前阶段、运行中操作、失败原因、版本和下一步入口。
- 重构本地媒体运行时，完善 Range、并发读取、取消、seek、重复打开和错误分类。
- 稳定引导式剪辑，加入镜头草稿、局部重渲染、历史版本和确定性缓存失效。
- 增加 Provider 能力预检与统一错误分类，在提交生成前提示模型和参数不兼容问题。
- 新增自包含 `.mora` 项目包，可备份、校验、删除后恢复、重渲染并再次导出。
- 新增本地诊断包，可逐文件预览并脱敏导出，不包含 Provider 凭据。
- 加固桌面升级与回退：升级前创建带校验和的数据库备份，迁移失败时自动恢复并写入说明。

## 桌面下载

本 Release 提供以下三个安装包，以及统一的 `SHA256SUMS.txt` 和 `INSTALLATION-NOTES.md`：

- Windows x64
- macOS Apple Silicon
- macOS Intel（兼容构建）

安装包由 GitHub Actions 在对应平台构建，并验证 standalone 运行时、SQLite、FFmpeg/ffprobe、本地 ASR、核心页面启动和安装包内应用冒烟测试。

## 安装与升级

下载后请先按照 `SHA256SUMS.txt` 校验安装包。已有 Mora 数据会在首次启动新版本、执行数据库迁移前自动备份；建议重要项目同时导出 `.mora` 项目包作为独立备份。

## 已知限制

- 本版本默认以 `unsigned` 开源安装包发布，尚未配置 Windows 代码签名或 Apple 签名与公证。系统可能显示未知发布者或 Gatekeeper 警告，请在校验 SHA-256 后按照安装说明人工放行。
- macOS Intel 由 CI 完成构建、架构检查和打包后冒烟验证；未声明 Intel 真机完整制作链路验收。
- 云端文本、图片、视频、素材和语音能力依赖用户自行配置的 Provider、网络、额度、地区可用性及服务条款。
- 自动生成内容和素材授权仍需用户在正式发布前人工检查。
