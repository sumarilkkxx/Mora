# Mora v0.2.1.0

此版本为 Pre-release（alpha），重点提升运行时稳定性、模块边界和自动剪辑评测能力。

## 更新

- 修复任务恢复、付费任务落库、合成轮询及内部接口校验中的边界问题。
- 整理领域类型、模板存储和调度依赖，减少模块之间的隐式耦合。
- 增加源码级 Agent Eval 工具，提供成本限制、开发集校准、评测指纹和 Holdout 门禁。
- 将内部评测项目与普通作品聚合隔离，避免评测数据进入产品统计。
- 修复跨平台 CI 对本地评测素材和毫秒级时钟偏差的错误依赖。
- 补充 Electron、CLI 与 Node 脚本的类型检查和回归覆盖。

## 下载与升级

请根据系统和芯片选择 Windows x64、macOS Apple Silicon 或 macOS Intel 安装包；`SHA256SUMS.txt` 提供文件校验值。
升级前建议备份 Mora 用户数据目录。新版本包含数据库迁移，首次启动时会自动应用。

## 已知限制

- 本版本尚未代码签名，macOS 安装包未公证。
- 云端文本、视觉、生成和语音服务仍取决于用户配置、网络、额度及服务商规则。
- 自动生成内容仍需人工检查后再发布。
